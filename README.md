🍽️ BiteRite

Personalized Recipe Generator & Community Platform

BiteRite is a full-stack web application that delivers AI-powered, personalized recipes based on users’ dietary preferences, health conditions, and fitness goals. It also includes a community forum where users can share recipes, interact, and discover new ideas.

🚀 Features
👤 Authentication
Secure login and signup using Clerk
Persistent user sessions
🧠 Personalized Experience
Guided onboarding to collect:
Diet preferences
Allergies
Health conditions
Fitness goals (e.g., weight loss, muscle gain)
Stores user data in MongoDB
🍳 Recipe Generation
AI-powered recipe generation using Gemini API
Tailored outputs based on user profile
Clean and structured recipe display
👥 Community Forum
Create posts with text and images
Like and comment on posts
Delete and manage your own posts
📝 User Profile
View and edit personal details
Update dietary and health preferences
Real-time database sync
🌙 UI/UX
Fully responsive design
Dark mode support
Smooth and modern interface
🛠️ Tech Stack

Frontend

React.js (Vite)
Tailwind CSS
React Router
Clerk Authentication

Backend

Node.js
Express.js
MongoDB (Mongoose)

APIs & Services

Gemini API (AI recipe generation)
Unsplash API (images)
⚙️ Installation & Setup
# Clone the repository
git clone https://github.com/your-username/BiteRite.git

# Navigate to project directory
cd BiteRite

# Install dependencies
npm install

# Run development server
npm run dev
